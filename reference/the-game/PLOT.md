# The Game (Newsey) — plot + build reference

**Full verbatim plot:** owner's message in Clubhouse PR #30
(`clubhouse/the-game`), 2026-08-19. This file is the structured build/art
reference distilled from it. Art must be 1:1 with the plot + the inspiration
images in this folder (`inspo-01..16.png`). Keep both.

## What the game is
A **Panel Attack** clone (Tetris Attack / Pokémon Puzzle League): a grid of
colored panels; the stack rises from the bottom; the player moves a 2-wide
cursor and swaps adjacent panels; match **3+** same-color in a row/column to
clear them; cleared panels drop by gravity and can trigger **chains/combos**
that send attacks to the opponent as **garbage blocks** that fall from the top.
Lose if the stack reaches the top. Reference source: `briankeegan/panel-game`
(Lua/LÖVE fork).

## Framing (drives look + levels)
The panel game is diegetic: it's a cursed 90s cartridge, **"Puzzle Attack"**,
that traps the player's soul in a realm called **Infinity**. Duels ARE the
panel game — winning sends real "attacks" (concrete slabs) at the opponent;
losing gets you "smashed flat." Top-down pixel art; the look can shift when you
enter a duel. Menu has an 8-bit chiptune vibe; a darker/"cursed" mode turns the
board **red** (vs the normal **pink**).

## Places
Infinity: your Victorian bedroom (giant mirror = menu/screen), the **Lounge**
(bar + portals to duels), the **Library** (city of bookshelves; jazz coffee
shop; reading room), the **Anarchy Garden** (waterfalls, crying-woman fountains,
CryBerries), Kyran's **Lab**. Bracelets encode rank (copper→silver→gold→diamond)
and playstyle (gem color). A day in Infinity = a minute in the real world; you
have ~1 hour (real) / ~59 "days" to escape or die.
