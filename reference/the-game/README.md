# New-game inspiration art

16 pixel-art reference images the owner supplied as the visual direction for the
new game (a Panel Attack clone). They had to be uploaded via the CLI session
because the live Clubhouse can't accept multiple image uploads at once (see
BACKLOG.md item 3).

These are **reference/style inputs**, not in-game assets. They should feed art
generation so the game's sprites/scenes are a 1:1 match to the plot and these
looks (see BACKLOG.md item 2). Downscaled to 512px to keep the repo lean;
originals were ~1024px.
